# How to Install Zonex Extension

## Quick Installation Guide

### Step 1: Open Chrome Extensions
1. Open Google Chrome or Microsoft Edge
2. Go to `chrome://extensions/` (for Chrome) or `edge://extensions/` (for Edge)
3. Or click the three dots menu → More tools → Extensions

### Step 2: Enable Developer Mode
1. Look for "Developer mode" toggle in the top-right corner
2. Turn it ON (it should be blue/green when enabled)

### Step 3: Load the Extension
1. Click "Load unpacked" button
2. Navigate to and select the `Zonex` folder (this entire folder)
3. Click "Select Folder"

### Step 4: Confirm Installation
1. You should see the Zonex extension appear in your extensions list
2. Look for the Zonex icon in your browser toolbar
3. If you don't see it, click the puzzle piece icon and pin Zonex

### Step 5: Start Using
1. Click the Zonex icon in your toolbar
2. The extension popup will open
3. Start converting timezones!

## Troubleshooting

### If the extension doesn't load:
- Make sure you selected the entire `Zonex` folder, not a file inside it
- Check that `manifest.json` is in the root of the selected folder
- Ensure Developer mode is enabled

### If icons don't appear:
- The extension uses SVG icons which should work in modern browsers
- Try refreshing the extensions page
- Disable and re-enable the extension

### If settings don't save:
- Make sure the extension has proper permissions
- Check browser console for any errors (F12 → Console tab)
